The basics

  • The GlassOS logo in the top-left corner opens the main menu: About This Computer, Settings, App Store, Help, Lock, Log Out, Restart and Shut Down.
  • The dock at the bottom holds your favourite apps. A dot under an icon means the app is open. Right-click an app in the dock and choose Keep in Dock or Remove from Dock.
  • Search with Super + Space. Type part of an app's name and press Enter. Super is the key with the Windows logo, or ⌘ on a Mac keyboard.
  • Move a window by dragging its title bar. Resize it by dragging any edge or corner. You can also hold Super and drag anywhere in a window to move it, or right-drag to resize it.
  • Desktops: Super + 1 to 9 switches between nine desktops, and Super + Shift + a number moves the current window there.
  • Shutting down always asks first. Choose Shut Down from the logo menu, or press Super + Alt + Backspace. A dialog counts down from 60 seconds, and Cancel, Esc or a click outside it stops it.

Getting apps

Open App Store from the dock or the app search. It lists the apps on Flathub, the largest catalogue of desktop Linux apps, run by a community foundation. Apps install for your account only and don't need an admin password.

  • Verified next to a developer's name means Flathub has checked that the app is published by the people who make it.
  • What the app can reach is listed on its page before you install it, in plain words: your files, the network, the microphone, and so on. You can switch any of these off later on the app's page under Installed.
  • Updates only happen when you press Update. Nothing installs in the background.
  • Removing an app removes it completely. Its saved data stays in your home folder (in .var/app) in case you install it again; the app's page offers to delete that too.

What the App Store sends

While it's open, the App Store downloads the catalogue, icons and screenshots from flathub.org, and installing downloads the app from there. Flathub counts how many times each app is downloaded. It doesn't get an account, a name or an email address, because there isn't one. When the App Store is closed it does nothing.

Other ways to install

  • Debian packages: GlassOS is built on Debian 13, so anything packaged for Debian installs with sudo apt install name in the Terminal. These are system-wide and need your password.
  • Firefox is already installed, for sites that don't work in Glass Browser.
  • AppImages (single-file apps some developers offer) run after you mark them executable: right-click in Files, Properties, Permissions.

Will my app work?

Most open-source apps do: LibreOffice, GIMP, Inkscape, Krita, Blender, VLC, OBS Studio, Audacity, Signal, Thunderbird. Many commercial ones are on Flathub too, such as Spotify, Zoom, Slack, Discord and Steam. Some aren't made for Linux at all, including Microsoft Office (use the web version in a browser) and Adobe's apps (Photopea, GIMP, Krita and Inkscape cover a lot of the same ground).

On a computer with an ARM processor, including a Mac running GlassOS in a virtual machine, some Flathub apps aren't available because their makers only publish them for Intel and AMD processors. The App Store only shows apps that can run on your computer.

Windows apps and games

  • Games: install Steam from the App Store. Steam's Proton runs a large share of Windows games; check a game on ProtonDB before you buy it. Games whose anti-cheat doesn't support Linux won't run. Steam is available on Intel and AMD computers only.
  • Other Windows programs: install Bottles from the App Store. It runs Windows programs through Wine. Plenty of older and simpler programs work; programs with strict copy protection, device drivers, or deep links to Windows usually don't.
  • If a program you depend on doesn't run, a Linux alternative or the program's web version is usually the more reliable path.

Privacy

GlassOS has no telemetry, no advertising ID, no online account and no location service. This is every connection the system makes on its own:

WhatWhere toWhen
ClockDebian's public time servers (debian.pool.ntp.org)Now and then, to keep the time right. Secure websites need a correct clock.
UpdatesDebian's servers (deb.debian.org)Only when you run Software Updates.
App Storeflathub.orgOnly while the App Store is open, or an app is installing.
Web searchDuckDuckGoOnly when you search from the browser's address bar.

Glass Lens shows every live connection on its Network page, so you can check this list yourself.

The top bar shows what's in use

An icon appears in the top bar whenever something is using your camera, microphone, screen or speakers. Point at it to see which app. Click it to open Settings, Privacy & Security, where you can:

  • quit the app that's using something, with one button;
  • switch the camera off for every app (the webcam driver is unloaded, so nothing can turn it on until you switch it back);
  • switch the microphone off for every app (every microphone is kept muted, including ones you plug in later).

Apps from the App Store also have their own switches: open the app's page under Installed.

Glass Browser

  • Cookies are kept, so sites remember that you're logged in. Cookies from other sites embedded in a page (third-party cookies, mostly used for tracking) are blocked.
  • Private windows (Ctrl + Shift + N) keep nothing after you close them.
  • Passwords aren't saved by Glass Browser yet. Firefox, which is also installed, can save them, and so can a password manager such as Bitwarden or KeePassXC from the App Store.

Sound packs

Every system sound (startup, log in, notifications, errors, plugging in a USB stick, volume changes) comes from a sound pack. A sound pack is a folder of audio files named after events, such as boot.wav, notification.ogg or error.flac. Open Sound Packs from the app search to hear every sound, switch packs, or import a folder of your own. Any event your pack leaves out falls back to the built-in sound.

Drivers and hardware

GlassOS uses Debian 13's Linux kernel and drivers, so it supports the same hardware as Debian. There's nothing to download for most computers.

  • Graphics: Intel and AMD graphics work with the included open-source drivers. NVIDIA cards use the basic open driver, which is slower; NVIDIA's own driver isn't included yet.
  • Wi-Fi and Bluetooth: firmware for the common Intel, Realtek, Atheros and Broadcom chips is included. If your Wi-Fi isn't found, connect a network cable and run sudo apt install firmware-misc-nonfree.
  • Without graphics acceleration (most virtual machines), GlassOS switches to lighter glass so the desktop stays smooth. You can choose this yourself in Settings, Appearance, Effects.
  • Printers and scanners aren't set up yet.
  • Glass Lens, Hardware shows your processor, memory, disks and graphics, and which driver the graphics use.

When something goes wrong

An app won't open

Open the Terminal and type the app's command (for example glass-settings). Any error is printed there.

An app stopped responding

Open Glass Lens, find it under Apps & Services, open it and click Quit this app. Super + Q also closes the window in front.

Everything feels slow

Glass Lens shows which app is using the processor and memory. In a virtual machine, choose Lighter in Settings, Appearance, Effects, and give the virtual machine more memory if you can.

A window is off the screen

Click it in the dock, then press Super + C to bring it back to the center.

See the system's own messages

Run journalctl -b in the Terminal for this startup's system log, or journalctl --user -t hyprland for the desktop's.
